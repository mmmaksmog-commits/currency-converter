# 💱 Курс

**Конвертер валют с актуальными курсами.**

### ▶️ [Открыть](https://mysik-portfolio.vercel.app/currency-converter/)

Работает на телефоне и на ПК, без установки и регистрации.

## Возможности

- 36 валют с флагами и русскими названиями (Intl.DisplayNames)
- Конвертация в обе стороны и обмен направления
- Популярные пары и избранные валюты
- Быстрая таблица сумм
- Кэш курсов на 12 часов и работа без сети

## Стек

JavaScript, Fetch API, Intl, open.er-api.com. Без фреймворков и сборки.

## Запуск локально

```bash
git clone https://github.com/mmmaksmog-commits/currency-converter.git
cd currency-converter
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
